## ▶️ How to Run

1.  Extract the project ZIP.
2.  Open `arpit-3d-portfolio` in VS Code.
3.  Put your photo at `assets/images/image.png`.
4.  Put your resume at `resume/Arpit-Sharma-Resume.pdf`.
5.  Install the **Live Server** extension in VS Code.
6.  Right-click `index.html`.
7.  Select **Open with Live Server**.

## 🔗 Update LinkedIn & GitHub

Search in the project for:

``` text
YOUR-LINKEDIN-LINK
YOUR-GITHUB-LINK
```

Replace these with your actual profile URLs.

## 🔗 Update Project Links

Open:

``` text
data/projects.js
```

Update each project’s `github` and `demo` URL.

Example:

``` javascript
{
  title: "Banking Data Analysis",
  github: "YOUR-GITHUB-REPOSITORY-LINK",
  demo: "YOUR-LIVE-DEMO-LINK"
}
```

Use your own repositories when presenting projects as your work.

## ➕ Add a New Project

Add another project object to `data/projects.js`:

``` javascript
{
  title: "New Data Analytics Project",
  description: "Project description.",
  tools: ["Python", "SQL", "Power BI"],
  github: "YOUR-GITHUB-LINK",
  demo: "YOUR-DEMO-LINK"
}
```
